## Features

### Delete with keyboard delete button
allow deletion from keyboard

### Lock a crop box
allow the user to lock each crop box, so that a different detection method can be tried without losing the crops that were correctly detected

### Select destination directory and file name format
Allow selection of the destination directory
Let the user supply a file name, onto which a number is appended - e.g. "party scans " to which 001, 002, 003 are added and so forth. Number should be the next increment from files already on disk
